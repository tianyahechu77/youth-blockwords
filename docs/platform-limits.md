# 平台设置路径与实测限制

按「先做哪个」排序，不要跳。词库是补漏，青少年模式才是主力。

---

## 一、抖音（Douyin）

### 1. 青少年模式（第一优先）

路径：

```
我 → 右上角三横 → 设置 → 青少年模式 / 未成年保护工具
```

要点：

- **一定要填出生年月**。分龄内容池是按年龄匹配的，不填就走通用策略，等于白开
- 设独立的 4 位密码，别用孩子能猜到的
- 时长设 40 或 60 分钟
- 2026 年 7 月起，青少年模式的推荐算法用多模态模型同时解析**画面、音频、文本**，AI 初筛 + 人工复审。这是唯一能「看懂画面」的一层

### 2. 屏蔽词（第二优先，补漏）

路径：

```
我 → 右上角三横 → 设置 → 更多功能 → 使用管理助手 → 内容管理 → 屏蔽设置 → 添加屏蔽词
```

实测限制：

- 单个词 **最多 5 个汉字**，界面显示 `0/5` 计数
- **不支持英文和数字**。`加V`、`ed`、`momo` 这类词无法生效（`ai生成美女` 能填进去但不生效）
- 名额几十个量级，各版本不同。**别一次填满**，会挤掉后续调整空间
- 每添加一个词，弹窗自动关闭，输入框每次都是空的
- **输入框为空时按退格键会直接关闭弹窗**

### 3. 评论区过滤（独立入口，容易漏）

```
创作者服务中心 → 互动管理 → 评论过滤
```

这里支持**一行一个词批量粘贴**，比标题屏蔽省事得多。评论区引流是擦边内容的主要入口之一。

### 4. 行为标记

- 刷到就长按 → `不感兴趣`。算法要连续标 5-7 次才会转向
- 顺手拉黑作者
- 明显违规直接举报（选「低俗色情」）
- 去 `隐私设置` 关掉「基于社交关系推荐」——朋友的点赞会把违规内容推进你的推荐池

### 5. 设备层兜底

iOS 用「屏幕使用时间」，安卓用「健康使用手机」，给抖音加应用限额 + 应用锁。孩子破解了 App 内的密码，还有这一层。

## 二、哔哩哔哩（B站）

B站 和抖音最大的区别：**不是一个屏蔽词列表，是四套彼此独立的清单。** 只设一套等于没设。

### 1. 首页推荐标题屏蔽词（上限 50）

```
我的 → 设置 → 隐私与推荐设置 → 个性化内容推荐管理 → 首页推荐标题屏蔽词 → 添加标题屏蔽词
```

建议先填 32 条，留 18 个余量给后续调整。清单见 `data/bilibili.txt` 的 `[title]` 段。

### 2. 弹幕关键词屏蔽（B站特有，最重要的一套）

```
播放页右下角齿轮 → 弹幕设置 → 屏蔽设置 → 关键词屏蔽
```

两个要点：

- **本地生效**，只影响这台设备看到的弹幕，不改推荐算法。所以可以比标题屏蔽更激进
- 弹幕是 B站 最脏的地方，而且**擦边弹幕是「画面干净、文字挑逗」**，词库对这类基本无效

### 3. 评论关键词过滤

```
视频页评论区 → 右上角三点 → 过滤消息 → 自定义关键词过滤
```

### 4. 动态屏蔽词

```
动态页任一卡片右上角三点 → 屏蔽设置 → 添加屏蔽词
```

或：`设置 → 隐私与推荐设置 → 内容屏蔽 → 动态与推荐关键词屏蔽`

### 5. 青少年模式（第一优先，能一票否决弹幕问题）

```
我的 → 下滑 → 青少年守护 → 青少年模式 → 设四位独立密码
```

开启后：**弹幕完全不可见且无法手动开启**、直播与充值关闭、默认每日 40 分钟。

这一条顶得上整个弹幕词库。

### 6. 亲子平台（B站 独有的远程管控）

```
青少年守护 → 亲子平台 → 绑定儿童账号
```

需家长与孩子双方实名认证。绑定后家长端可看**最近 7 日内容分类统计、在线状态、当日观看时长**，并可远程设屏蔽词。抖音没有对等能力（只有亲子护航）。

### 7. PC 端增强：Bilibili Evolved

浏览器装这个开源插件后，可在「进阶屏蔽」里对标题、简介、UP 主、分区做**正则级过滤**，能力和词量都不受 50 个名额限制。

适合家长在自己电脑上做「先筛一遍」，但**管不到手机 App**。

## 三、三个平台都拦不住的地方

这不是配置问题，是机制问题：

| 渠道 | 为什么词库拦不住 |
|---|---|
| 画面本身 | 屏蔽词只匹配标题/文案/话题词 |
| 私信与群聊 | 不经过推荐流 |
| 网盘链接 | 分享在站外完成 |
| 评论区暗语 | 变形快，且平台不保证同一套词作用于评论 |
| 拼音缩写、拆字、表情替代 | 平台官方说明里明确不识别 |

所以：词库做到头，也只能覆盖「文字引流」这一层。剩下的靠青少年模式、设备级管控、和跟孩子把话说开。
