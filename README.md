# 青少年内容防护 · 屏蔽词库 + 批量填入脚本

一套给家长（或给自己）用的短视频平台屏蔽词库，外加一个把词**批量填进抖音**的 ADB 脚本。

抖音的屏蔽词只能在手机 App 里一条一条手输，网页端没有入口。30 个词手动输要十几分钟，脚本压到两分钟以内。

---

## 先说清楚它拦不住什么

这一节比后面所有内容都重要。

| 它能做到 | 它做不到 |
|---|---|
| 拦掉标题/文案里带引流黑话的视频 | **挡不住画面**。屏蔽词只匹配标题、文案、话题词，不识别画面 |
| 拦掉已知的圈层暗语（`梦回大唐`、`养兔子`） | 挡不住私群、网盘、评论区引流 |
| 拦掉谐音辱骂和诈骗话术 | 挡不住空标题 + 纯画面的擦边内容 |

擦边内容的典型特征恰恰是「**画面出问题、文案很干净**」，所以词库对它是结构性无效的。真正能看懂画面的是平台自带的**青少年模式**（2026 年 7 月起抖音用多模态模型同时解析画面、音频、文本）。

**结论：词库是补漏，青少年模式才是主力。** 顺序别搞反。

## 平台实测限制

以下全部是实测结果，不是文档抄的：

| 项目 | 抖音 | 哔哩哔哩 |
|---|---|---|
| 屏蔽清单数量 | 1 套（仅标题） | 4 套：标题 / 弹幕 / 评论 / 动态 |
| 单词长度上限 | **5 个汉字** | 未见同级别限制 |
| 英文 / 数字词 | **不支持**（`加V`、`ed` 实测无法生效） | 支持 |
| 名额上限 | 几十个量级（各版本不同） | 标题屏蔽词 50 个 |
| 弹幕 | 无独立屏蔽入口 | 独立清单，且是孩子受害最深的入口 |
| 青少年模式 | 分龄内容池 + 多模态识别 | 弹幕完全不可见且无法开启 |
| 家长远程管控 | 亲子护航 | 亲子平台（可看观看记录 + 设屏蔽词） |
| PC 端增强 | 无 | Bilibili Evolved 插件（正则级，不受名额限制） |

另外两个实测出来的坑：

- 每添加一个词，弹窗会自动关闭，输入框每次都是空的
- 输入框为空时按退格键会**直接关闭弹窗**

## 词库

```
data/
├── words.json                结构化词库：36 组 453 词，含分组说明、优先级标签、逐组备注
├── douyin-recommended.txt    ★ 推荐先填的 30 条（按危害排序，全部符合抖音规则）
├── douyin-all.txt            抖音可用全量 431 条（纯中文、≤5 字，已去重）
└── bilibili.txt              B站四套清单（title / danmaku / comment / dynamic）
```

`words.json` 每组带三个字段：

- `scope`：`kid` 只建议给孩子账号用 / `both` 都建议 / `care` 特殊处理 / `opt` 看情况
- `tag`：优先级标签
- `note`：这组为什么危险、怎么用

**优先填 `douyin-recommended.txt`**。理由是名额只有几十个：`梦回大唐` 拦的是窒息游戏，`风水` 拦的是一种观点，同样占一个名额，优先级不该一样。

### 关于「情绪危机」这一组

词库里有一组（抑郁、想死、轻生等）标注为 **不建议屏蔽**。

理由不是心软，是实用：把这些词屏蔽掉会有两个后果——孩子真的痛苦时搜不到任何求助内容，同时你也失去了最早的预警信号。**屏蔽方法词（烧炭、跳桥），保留情绪词（抑郁、想死）。**

## 快速开始

### 方式 A：手动填（推荐，最省事）

打开 `data/douyin-recommended.txt`，把 30 个词逐个粘进：

```
我 → 右上角三横 → 设置 → 更多功能 → 使用管理助手 → 内容管理 → 屏蔽设置 → 添加屏蔽词
```

不装任何东西，不碰系统设置。只是慢一点。

### 方式 B：脚本批量填

前置条件三条，缺一不可：

1. **Windows + PowerShell 5.1+**，且 `adb` 可用（[platform-tools](https://developer.android.com/tools/releases/platform-tools)）
2. **手机开启「USB 调试」和「USB 调试（安全设置）」**。后者在小米/Redmi 上是独立开关，不开的话 `input tap` 会被拒：
   `Injecting input events requires the INJECT_EVENTS permission`
   **改完开关必须重新插拔数据线才生效**，这个坑会浪费你半小时。
3. **手机上装了支持跨设备剪贴板的输入法**，并已开启该功能。
   微信输入法实测可用（Windows 端 + Android 端同时登录）。

跑起来：

```powershell
# 第一次：先校准坐标（换机型/换分辨率/换 App 版本都要重做）
.\scripts\fill.ps1 -Adb "D:\platform-tools\adb.exe" -Calibrate

# 试填 3 个词，确认流程通
.\scripts\fill.ps1 -File ..\data\douyin-recommended.txt -Adb "D:\platform-tools\adb.exe" -Count 3 -Verify

# 全量填，快速模式
.\scripts\fill.ps1 -File ..\data\douyin-recommended.txt -Adb "D:\platform-tools\adb.exe"
```

参数：

| 参数 | 说明 |
|---|---|
| `-File` | 词表路径，一行一词，`#` 开头为注释 |
| `-Words` | 直接给词，逗号分隔 |
| `-Adb` | adb.exe 路径，默认从 PATH 找 |
| `-Verify` | 逐词回读校验，失败自动关弹窗重试。约 9 秒/词，但不会连续污染列表 |
| `-Calibrate` | 读一次界面，打印三个关键控件的实际坐标 |
| `-DryRun` | 只打印要填什么，不动手机 |
| `-Start` / `-Count` | 从第几个开始、填几个 |
| `-AddX` `-AddY` `-BoxX` `-BoxY` `-SubmitX` `-SubmitY` | 手动指定坐标 |

快速模式约 **4 秒/词**，逐词校验模式约 **9 秒/词**。再快不了——弹窗动画、键盘弹出、剪贴板同步各自要几百毫秒。

## 它是怎么工作的

`adb shell input text` **不支持中文**，只能发 ASCII。Android 10+ 的 `service call clipboard` 接口也已失效（Android 16 上直接报 Parcel 错误）。所以中文只能靠剪贴板接力：

```
电脑写 Windows 剪贴板
   ↓  输入法跨设备同步
手机剪贴板
   ↓  adb shell input keyevent 279（粘贴键）
抖音输入框
```

脚本只负责第 1 步和第 3 步，第 2 步靠你手机上的输入法。

**不要**去点输入法面板上显示的那个候选词。那块面板不在 Android 的 UI 树里，`uiautomator dump` 抓不到，坐标只能靠猜——这是最容易走偏的一条路。

## 安全与隐私

- 脚本本身不上传任何数据，不联网，不读通讯录。
- **但剪贴板接力意味着：你填的每个词都会经过输入法厂商的服务器。** 这些词本身不敏感（`蓝鲸`、`虐猫`），但如果你连这个都不接受，就用手动方式 A。
- 仓库里不含任何个人路径、设备序列号、账号信息。
- 只在自己拥有、或自己作为监护人有权管理的设备上使用。

## 数据来源

本仓库的词不是拍脑袋想的，主要来自：

1. **抖音黑板报**《抖音关于持续治理涉未成年人不良内容的公告》2026-10
2. **央视网** 2026-01《这些「加密术语」，可能伤害我们的孩子！》——`梦回大唐`、`ED妹`、`梦角哥` 均出自此
3. **央视《法治在线》** 2026-04 暗黑动漫调查——`喰种`、`食尸鬼`、`东京吃货` 谐音马甲
4. **中国网络社会组织联合会 × 抖音**《未成年人新型网络风险防护指南》2026-08
5. **中央网信办**「清朗·未成年人网络保护」专项行动相关通报

### 关于现成的开源词库

调研过，但**没有一个是为青少年场景做的**：

| 项目 | 规模 | 为什么不直接用 |
|---|---|---|
| [houbb/sensitive-word](https://github.com/houbb/sensitive-word) | 6 万词，Java/DFA，带分类标签，Apache-2.0 | 面向 UGC 平台通用审核，不分年龄段 |
| [fwwdn/sensitive-stop-words](https://github.com/fwwdn/sensitive-stop-words) | 分类 txt：色情 304 / 涉枪涉爆 430 / 政治 325 / 网址 1.45 万 | 唯一能直接拿来用的格式，但主题不是「青少年」 |
| [RunEnd/Sensitive-lexicon](https://github.com/RunEnd/Sensitive-lexicon) | 17 个文件约 1.2 MB，十万条量级 | 政治类占大头，与本场景无关 |

实测把色情类 304 词按抖音规则过一遍：**289 条纯中文、289 条全部 ≤5 字，一条都没被规则淘汰。**

也就是说——**词的来源从来不是瓶颈，筛选和名额才是。** 把 6 万词倒进来，手机上能填的还是那几十个。所以本仓库只做精选，不做堆量。

## 贡献

欢迎 PR 补充词条，但请遵守两条：

1. **单个词不超过 5 个汉字、纯中文**（英文和数字抖音填不进去）
2. 提交时说明**来源和危害**——「这个词为什么该拦」比词本身重要。没有依据的臆造词会被拒

另外，**不建议纯堆量**。加 100 个低价值词会挤掉 100 个高价值词的位置，这不是提升。
